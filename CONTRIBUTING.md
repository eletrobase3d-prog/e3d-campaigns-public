# Contribuições

Este repositório serve como portfólio de código visível sob reserva de direitos. Antes de propor redistribuição ou mudanças extensas, alinhe a contribuição com o mantenedor. Não há concessão automática de licença ampla.

Use dados sintéticos, preserve isolamento de organizações e auditoria transacional, e descreva o problema e a validação na proposta. Nunca inclua ambientes reais. Execute scripts/check-public.py antes de publicar arquivos. As mudanças na versão pública devem ser coordenadas com a fonte privada para não perder correções futuras.
