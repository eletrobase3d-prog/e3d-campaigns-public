# Contribuições

Obrigado pelo interesse no E3D Campaigns. Este portfólio não oferece licença ampla de reutilização; consulte LICENSE antes de propor alterações de código.

Sugestões de produto, dúvidas técnicas e correções de documentação podem ser discutidas em issues sem dados privados. Para código ou materiais de terceiros, combine previamente o escopo e a autorização com o mantenedor. Abrir uma issue não altera o licenciamento, e nenhuma cessão ampla de direitos é presumida.

Ao preparar uma contribuição autorizada:

1. Descreva o problema e o comportamento esperado.
2. Faça uma alteração pequena e coerente com a documentação.
3. Use somente dados sintéticos e preserve avisos de terceiros.
4. Registre verificações realizadas e limitações; não afirme testes que não executou.
5. Atualize o roadmap quando houver mudança comprovada de estado.

Não inclua ambientes, dumps, logs de produção ou dados pessoais. Problemas de segurança seguem SECURITY.md.
